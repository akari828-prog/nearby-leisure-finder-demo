# スマホだけでAPKをインストールする手順

パソコンやFlutterのインストールは不要です。GitHub ActionsがAPKを作り、スマートフォンのブラウザーから取得できます。

## APKを入れる

1. [Releasesページ](https://github.com/akari828-prog/nearby-leisure-finder-demo/releases) をスマートフォンで開きます。
2. 最新の **Android free build** を選びます。リリースにまだ表示されていなければ、無料版の自動ビルドが終わるまで待ちます。
3. Assetsから nearby-leisure-free.apk を選んでダウンロードします。
4. ダウンロード通知または「Files」アプリの「ダウンロード」からAPKを開きます。
5. Androidが求めた時は、APKを開いたブラウザーまたはファイルアプリに「この提供元のアプリを許可」を設定し、「インストール」を押します。

## 初回検索

アプリを開いて「現在地から探す」を押します。その時に位置情報の許可が求められます。位置情報サービスがオフなら端末の位置情報をオンにして、もう一度検索してください。

## 費用とデータ

- Firebase、Gemini API、APIキー、支払い方法は使いません。
- RSS候補は端末内のキーワードで分類します。イベント名・短い説明・出典・元記事リンクを表示します。
- RSSに開催場所が書かれている候補だけ距離を計算します。情報を推測で補いません。
- GPSはボタンを押した時だけ取得し、距離計算は端末内で行います。地域名だけをRSS検索に使います。
- 広告はGoogle公式テスト広告IDです。
