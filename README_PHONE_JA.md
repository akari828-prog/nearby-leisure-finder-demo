# スマホだけでAPKをインストールする手順

## APKをダウンロード

[Android free build 7（nearby-leisure-free.apk）をダウンロード](https://github.com/akari828-prog/nearby-leisure-finder-demo/releases/download/android-free-37396900610-1/nearby-leisure-free.apk)

ファイルサイズは約48.7 MBです。実機でのインストール・起動はまだ確認できていません。GitHub Actionsでは静的解析、テスト、APKビルド、署名検証が成功しています。

1. Androidスマートフォンで上のリンクを開き、APKをダウンロードします。
2. ダウンロード通知をタップするか、「Files」アプリの「ダウンロード」からAPKを開きます。
3. Androidが確認を出した場合だけ、APKを開いたブラウザーまたはファイルアプリに「この提供元のアプリを許可」を設定します。
4. インストール画面で「インストール」を押します。
5. アプリを起動し、「現在地から探す」を押した時に位置情報を許可します。

## 位置情報と費用

- Firebase、Gemini API、APIキー、支払い方法は使いません。
- RSSの候補を端末内のキーワードで分類します。RSSに開催場所が書かれた候補だけ距離を計算します。
- GPSは検索ボタンを押した時だけ取得し、距離は端末内で計算します。RSS検索には市区町村などの地域名を使います。
- 広告はGoogle公式テスト広告IDです。

## エラー時

位置情報サービスをオンにして再検索してください。イベントが表示されない時は、RSSの掲載内容や開催場所の記載が不足している可能性があります。時間をおいて再検索してください。
